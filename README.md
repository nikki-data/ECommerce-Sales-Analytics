# E-Commerce Sales Analytics Dashboard

## Project Overview
This project focuses on analyzing e-commerce sales data to identify business trends, evaluate sales performance, and generate actionable insights using Microsoft Excel.

## Dataset Information
- Total Transactions: 138,116
- Total Columns: 46
- Domain: E-Commerce
- Tool: Microsoft Excel

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Excel Formulas
- Data Visualization
- GitHub

## Key Performance Indicators (KPIs)
- Total Transactions
- Total Revenue
- Total Profit
- Total Customers
- Average Order Value
- Return Rate
- Cancellation Rate
